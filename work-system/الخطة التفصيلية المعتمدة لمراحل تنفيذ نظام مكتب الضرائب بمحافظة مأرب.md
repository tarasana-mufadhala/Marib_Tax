# **الخطة التفصيلية المعتمدة لمراحل تنفيذ نظام مكتب الضرائب بمحافظة مأرب**

## **الهدف النهائي**

بناء منظومة تشغيلية متكاملة تتكون من:

* تطبيق Android للمكلفين باستخدام Flutter.
* لوحة إدارة للموظفين والمدير باستخدام Next.js.
* موقع إلكتروني عام لمكتب الضرائب.
* Backend مركزي باستخدام NestJS.
* قاعدة بيانات PostgreSQL عبر Supabase.
* نظام مرفقات ووثائق خاص وآمن.
* إشعارات داخل التطبيق وPush وSMS.
* تقارير إدارية وتشغيلية ومالية.
* استيراد منظم للبيانات القديمة.

المعمارية المعتمدة تمنع تطبيق Flutter أو لوحة Next.js من تنفيذ عمليات مباشرة على جداول التشغيل؛ جميع الإجراءات تمر عبر NestJS وقواعد الصلاحيات والخدمات الخلفية.
