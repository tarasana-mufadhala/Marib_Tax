# docs/architecture/adr

Architecture Decision Records for the Marib Tax System.

**Purpose:** Accepted decisions that constrain implementation. Changes require formal change control.

**Status:** Foundational ADRs (ADR-001 through ADR-015) are present. API/runtime, fail-closed authorization, the first request-draft contract, and the Supabase Auth current-actor boundary are authorized by API-01 through API-04. ADR-015 records approved business data boundaries for tax numbers, v1 account linkage, manual payment evidence, visit entry, attachment archive versions, notification provider port intent, and report field/export separation. Production operations remain separately gated.
