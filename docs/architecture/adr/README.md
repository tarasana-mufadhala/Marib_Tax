# docs/architecture/adr

Architecture Decision Records for the Marib Tax System.

**Purpose:** Accepted decisions that constrain implementation. Changes require formal change control.

**Status:** Foundational ADRs (ADR-001 through ADR-014) are present. API/runtime, fail-closed authorization, the first request-draft contract, and the Supabase Auth current-actor boundary are authorized by API-01 through API-04; production operations remain separately gated.
